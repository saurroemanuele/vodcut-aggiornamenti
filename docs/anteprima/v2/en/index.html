FAQ

Is it free?

The desktop app is. Web clips unlock from €3.99, and a plan gives you more AI credits.

Which platforms does it take streams from?

Twitch, YouTube and Kick. You can also upload a video you already have on your computer.

Which computers does it run on?

Windows and Mac.

How do I open the app the first time?

Windows: if a warning shows up, click More info and then Run anyway.
Mac: drag NoonFrame to Applications and, the first time only, paste this in Terminal

xattr -cr /Applications/NoonFrame.app && open /Applications/NoonFrame.app
